# 📜 Bitácora de Decisiones Arquitectónicas (ADR) - AUM-IC Tailwind Killer

| Timestamp | Contexto | Decisión | Consecuencia |
|-----------|----------|----------|--------------|
| 2026-09-24 | El transpilador inicial con RegEx fallaba ante la lógica matemática de React/Astro (`className={ activo ? 'bg-red' : '' }`). | Inyectar compilador `@babel/parser` (AST Interceptor) para JSX/TSX. Mantener RegEx Universal solo como Fallback para lenguajes como Python, PHP, Rust. | Mayor precisión quirúrgica en ecosistemas JS. El código lógico del framework queda 100% intacto, solo mutan los literales de texto. |
| 2026-09-24 | Generar nombres de clases con hashes deterministas (`aumic-btn-8f92`) es veloz pero incomprensible para programadores humanos. | Inyectar Adaptador Universal de Inteligencia Artificial como módulo Opcional. Soporta Gemini, Claude y un adaptador compatible OpenAI (Codex, DeepSeek, xAI, Qwen). | Permite "magia semántica" (ej. `aumic-btn--danger`) sin bloquear la eficiencia offline. Mantiene dependencias ligeras usando `fetch` nativo sin SDKs externos. |
| 2026-09-24 | Analizar jerarquía de AUM-IC en código sin semántica HTML5 (la temida "Sopa de Divs"). | Construir Motor de Heurística de Nombres que lee el nombre del componente (ej. `Button` -> Átomo, `Layout` -> Ecosistema) para depositar el SCSS modular en la carpeta correcta. | Generación de la estructura base AUM-IC automáticamente en el proyecto destino. |
| 2026-09-24 | El CLI interactivo guiaba bien pero bloqueaba a usuarios de CI/CD. Vulnerabilidades detectadas en npm de Tailwind. | Implementar el paquete `commander` para banderas por consola (`--mode`, `--ai`). Añadir comando de Erradicación Automática post-mutación. Ejecutar `npm audit fix` para limpiar CVES. | El CLI es híbrido (Interactivo o Banderas). Dependencias del repositorio 100% seguras y saneadas. |
| 2026-09-24 | Posibilidad de transmutar sitios web externos directamente desde la red. | Inyectar **Modo Parásito** con `website-scraper`. Permite clonar web única (`page`) o entera (`site`), mutando el archivo `.css` extraído en lugar de depender del JIT local inexistente. | Capacidad ofensiva de OSINT o rescate de sitios ajenos, listos para correr offline en entorno local. |
